# Stop&Eat - Documentación del Proyecto

Proyecto académico desarrollado para la asignatura Metodología de Desarrollo de Software (MDS) de la Tecnicatura Universitaria en Programación (TUP Plan 2003) - UTN Facultad Regional Haedo.

---

## Descripción del Proyecto

Este repositorio contiene la documentación oficial del trabajo práctico **Stop&Eat**.

Incluye:
- La consigna del trabajo
- Definición de objetivos, límites y alcance del sistema
- Documentación según la Metodología de Desarrollo de Software (TPI MDS)

Stop&Eat es un sistema orientado a la gestión y control de un negocio gastronómico / servicio de comida.

---

## Contenido del repositorio

- **Consigna Stop&Eat.pdf**  
  Enunciado oficial del trabajo práctico.

- **Objetivo, limite y alcance Stop&Eat.pdf**  
  Documento que define el objetivo general, los límites y el alcance del sistema a desarrollar.

- **TPI_MDS_v93.pdf**  
  Documentación elaborada siguiendo la Metodología de Desarrollo de Software (versión 9.3).

---

## Tecnologías / Herramientas utilizadas

- Documentación técnica según metodología MDS
- Herramientas de ofimática para la elaboración de los artefactos
